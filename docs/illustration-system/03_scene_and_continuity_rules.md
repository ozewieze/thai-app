# Scene & Continuity Rules

Dit hoofdstuk regelt hoe een enkele dialoog als samenhangende visuele reeks wordt behandeld: één permanente omgeving (de Scene Bible), met per slide alleen kleine, toegestane veranderingen.

## Dialogue Scene Bible

Definieert de permanente omgeving voor een volledige dialoog. Elke dialoog krijgt precies één Scene Bible, ongeacht het aantal slides.

```
Location
[Insert location]

Time of day
[Insert time]

Weather
[Insert weather]

Environment
[Insert environmental details]

Mood
[Insert mood]

Visual Density
Clean and uncluttered unless specified otherwise.

Color Palette
[Insert palette if relevant]
```

Zie `templates/scene-bible.template.md` voor het volledig invulbare template en `scene-bibles/a1_dialog_01_scene_bible.md` voor een ingevuld voorbeeld.

## Scene Continuity Rule

Keep consistent across all slides:

- location
- lighting
- weather
- architecture
- furniture
- environmental objects
- atmosphere
- palette

**Treat every slide as occurring only seconds before or after the previous slide.**

## Dialogue Slideshow Rules

This illustration belongs to a slideshow sequence. The slideshow should feel like one continuous conversation.

### Allowed Changes Between Slides

Characters may change:

- posture
- gaze direction
- facial expression
- hand gestures
- body orientation
- conversational distance

### Avoid Large Changes

Avoid changing:

- camera angle
- environment
- mood
- lighting
- scene layout

unless explicitly requested.

## Dialogue Composition Rules

Create illustrations optimized for a language-learning lesson page. Use:

- medium-wide composition
- horizontal format
- clear visibility of main characters

Avoid:

- extreme close-ups
- movie-poster compositions
- portrait hero compositions

The scene should remain readable inside a wide slideshow card.

## Hoe dit de slide-segmentatie stuurt

Deze regels bepalen niet alleen hoe een illustratie wordt getekend, maar ook **hoe een dialoog in slides wordt opgeknipt** (zie `04_illustration_workflow_guide.md`, sectie "Slide-segmentatie"). Omdat scène, camera en belichting tussen slides niet mogen veranderen, is een slide-wissel altijd gemotiveerd door een verandering in het **gespreksmoment** (wie spreekt, welke emotie, welk gebaar) — nooit door een visuele reden. Dit voorkomt willekeurige knippen en houdt de slideshow herkenbaar als één doorlopend gesprek.
